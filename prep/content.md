# Content
Topic: Forensics

## Overview/Introduction/Context
* Crime scene investigators use technology to collect, examine, and analyze evidence.
* Software helps investigators analyze DNA, compare fingerprints, examine digital evidence, and organize case information.


## Part A: existing technology

##### Software
1. Codis
  * CODIS compares DNA profiles to help investigators find possible matches between crime scene evidence and DNA databases.
  * https://www.fbi.gov/how-we-can-help-you/dna-fingerprint-act-of-2005-expungement-policy/codis-and-ndis-fact-sheet

2. Next Generation Identification (NGI)
* NGI helps law enforcement search fingerprint records and other biometric information to identify people.
* https://le.fbi.gov/science-and-lab/biometrics-and-fingerprints/biometrics/next-generation-identification-ngi
  
  3. OSIRIS
* OSIRIS is software that helps forensic laboratories review and analyze DNA data.
  
4. GeneMapper ID
* GeneMapper ID helps forensic scientists analyze DNA markers and genetic profiles.

6. GeneMapper ID-X
* GeneMapper ID-X helps forensic laboratories examine DNA analysis results.

7. TrueAllele
* TrueAllele uses statistical methods to help forensic scientists analyze complex DNA mixtures.
  
8. Autopsy
* Autopsy helps investigators examine computer files and other digital evidence.
  
9. EnCase Forensic
* EnCase Forensic helps investigators examine and report digital evidence from electronic devices.

10. Magnet AXIOM
* Magnet AXIOM helps investigators examine digital evidence from computers and mobile devices.

11. Cellebrite
* tools help forensic professionals examine digital information from electronic devices.

12. X-Ways Forensics
* X-Ways Forensics helps investigators examine storage devices, search files, and organize digital evidence.

13. PhotoRec
* PhotoRec helps recover certain lost or deleted files from storage devices.
  
14. NIST Computer Forensics Tool Catalog
* This catalog provides information about tools used to examine digital evidence.

15. Laboratory Information Management System (LIMS)
* LIMS helps forensic laboratories track evidence samples, test results, and laboratory records.
